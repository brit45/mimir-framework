## Résultat attendu

Tu peux appeler l'API sans ambiguïté de signature ou de comportement.


> **Introduit dans la série 3.0, disponible en 3.1.0**

Source : `src/scriptings/Lua/luaScripting/LuaScripting.cpp`.

`Mimir.IO` expose des opérations de lecture/écriture de fichiers image (et potentiellement d'autres médias à l'avenir).

Le contrat actuel est volontairement minimal : lire un fichier image, récupérer un buffer RGB 8 bits, puis laisser le script décider comment le normaliser et le remodeler pour un modèle donné.

## Fonctions

### `Mimir.IO.read_image_rgb_u8(path: string) -> table<int> | (nil, err)`

Charge une image depuis le disque et retourne ses pixels sous forme d'une table Lua d'entiers (RGB, 8 bits par canal).

| Paramètre | Type | Rôle |
| --- | --- | --- |
| `path` | string | Chemin absolu ou relatif vers le fichier image (PNG, JPEG…) |

Retour :

- `table<int>` : pixels sous forme `{R, G, B, R, G, B, …}` (entiers 0–255)
- `nil, err` : si le fichier est introuvable ou illisible

> Note : les dimensions (largeur, hauteur) ne sont pas retournées par cette version de l'API. Si tu as besoin des dimensions, lis-les depuis les métadonnées du fichier séparément.

### Alias global

L'alias `readImageRGBU8` est disponible comme global direct :

```lua
local px = readImageRGBU8("./dataset_2/img0001.png")
-- équivalent à :
local px = Mimir.IO.read_image_rgb_u8("./dataset_2/img0001.png")
```

## Exemple d'utilisation

```lua
-- Charger une image RGB
local pixels, err = Mimir.IO.read_image_rgb_u8("./dataset_2/img0001.png")
if not pixels then
    error("Impossible de charger l'image : " .. tostring(err))
end

-- Compter le nombre de pixels
local n_pixels = math.floor(#pixels / 3)
log(string.format("Image chargée : %d pixels (brut: %d valeurs)", n_pixels, #pixels))

-- Normaliser les pixels (0–255 → 0.0–1.0)
local normalized = {}
for i = 1, #pixels do
    normalized[i] = pixels[i] / 255.0
end

-- Utiliser comme entrée d'un forward (ex. VAE ou UNet)
local out = Mimir.Model.forward({ __input__ = normalized }, false)
```

À retenir : cette API ne reconstruit pas automatiquement un tenseur 2D/3D avec largeur et hauteur. Elle fournit un buffer linéaire pratique pour un prétraitement Lua explicite.
